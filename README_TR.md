# Sosyal Medya Otomasyonu

[English](README.md) | [Türkçe](README_TR.md)

Bu depo bir sosyal medya otomasyon projesi için ayrılmıştır. Uygulama kodu ve kullanım talimatları henüz yayımlanmamıştır.

Herhangi bir platformda otomasyon kullanmadan önce güncel hizmet şartlarını, API kurallarını, hız sınırlarını ve gizlilik gereksinimlerini inceleyin.
